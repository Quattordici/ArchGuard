# Archie
Architecture rules for .NET, enforced at compile time. Roslyn analyzers turn layering, dependency and naming violations into build errors and IDE diagnostics with exact file and line.

> **Status: early development.** The `0.0.x` pre-releases on NuGet contain no architecture rules yet; they only report ARCH909 (no `archie.json` found). Don't use them in a real project.
